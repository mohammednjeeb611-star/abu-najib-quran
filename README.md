# مقرأة أبو نجيب السلمي لتحفيظ القرآن الكريم

مقرأة إلكترونية مجانية ومفتوحة للجميع، صُممت لمساعدة المسلم على قراءة القرآن الكريم، وحفظه، ومراجعته، والاطلاع على تفسيره، والاستماع إلى تلاواته دون الحاجة إلى إنشاء حساب أو وجود معلم، مع دعم كامل للعمل دون إنترنت (Offline) وتثبيته كتطبيق على الهاتف (PWA).

## أبرز الخصائص
- **المصحف الشريف:** عرض السور الـ 114 بالرسم العثماني (`quran-uthmani`) مع التنقل بالسورة أو الجزء أو الحزب، والبحث، وتكبير/تصغير الخط، وحفظ آخر موضع قراءة، والنسخ والمشاركة.
- **التفسير الموثق:** عرض تفسير الآية عند النقر عليها أو عبر زر التفسير مع اختيار كتاب التفسير وتوثيق المصدر دون اختلاق أو تأليف.
- **التلاوة الصوتية:** اختيار القارئ، تشغيل السورة أو آية محددة، تكرار الآية أو مجموعة آيات، التحكم بسرعة التشغيل، تنزيل السور إلى الجهاز مع إظهار التقدم والحجم والإيقاف/الاستئناف وعدم إعادة التنزيل المكرر، وحذف التلاوات لإخلاء المساحة.
- **الحفظ والتسميع الذاتي:** تحديد السورة ونطاق الآيات، عدد التكرار، الاستماع قبل الحفظ، إخفاء/إظهار نص الآية، اختبار إكمال بداية الآية، تسجيل آيات المراجعة، خطة يومية، جدول مراجعة أسبوعي، ونسبة إنجاز محفوظة محلياً.
- **التخزين والعمل أوفلاين:** استخدام `IndexedDB` للنصوص والتفاسير والبيانات الوصفية، و`Cache API` مع `service-worker.js` للملفات والصوتيات.
- **التواصل:** زر واتساب مباشر لإدارة المقرأة (`00967735018955` — `https://wa.me/967735018955`).
